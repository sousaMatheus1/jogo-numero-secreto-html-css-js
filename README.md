# 🔢 Jogo do Número Secreto

Este projeto é um jogo interativo de adivinhação onde o usuário tenta descobrir o número secreto gerado pelo sistema. Ele marca a minha transição do HTML/CSS puro para a lógica de programação dinâmica com **JavaScript**.

## 🛠️ Tecnologias e Conceitos Aplicados

* **JavaScript (ES6+):** Utilizado para toda a inteligência do jogo.
* **Manipulação de DOM:** Integração do script com elementos HTML (textos, botões e campos de entrada).
* **Responsive Voice:** Implementação de síntese de voz para tornar o jogo acessível e interativo.
* **HTML5 e CSS3:** Estrutura e estilização da interface visual.

## 📖 Jornada de Desenvolvimento (Lógica de Programação)

O projeto foi construído e evoluído através de dois módulos fundamentais na Alura:

### 1. Mergulhando em Programação com JavaScript
* **Carga Horária:** 6 horas
* **Link:** https://cursos.alura.com.br/course/logica-programacao-mergulhe-programacao-javascript
* **Desafio:** Construir a base do jogo onde o computador gera um número aleatório e o usuário precisa adivinhá-lo.
* **Solução & Aprendizado:** Apliquei os conceitos fundamentais de **variáveis**, **condicionais (`if/else`)** para verificar se o chute era maior ou menor, e **loops (`while`)** para gerenciar as múltiplas tentativas do jogador. Foi meu primeiro contato prático com a resolução de problemas através de algoritmos.

### 2. Explorando Funções e Listas
* **Carga Horária:** 6 horas
* **Link:** https://cursos.alura.com.br/course/logica-programacao-funcoes-listas
* **Desafio:** Refatorar o código para torná-lo mais organizado, visualmente atraente e adicionar memória ao jogo.
* **Solução & Aprendizado:** * **Funções:** Organizei o código em funções com parâmetros e retornos, facilitando a leitura e manutenção.
    * **Listas (Arrays):** Implementei um sistema para que o jogo não repita números que já foram sorteados anteriormente, utilizando métodos de listas.
    * **Interatividade:** Melhorei a experiência do usuário integrando o JavaScript com o HTML para exibir mensagens dinâmicas na tela e limpar o campo de entrada automaticamente.

## 🚀 Como Jogar

Você pode testar o jogo agora mesmo através do link abaixo:

🔗 [Link do Jogo Online (Vercel)](https://jogo-numero-secreto-html-css-js.vercel.app/)

**Instruções:**
1. Digite um número no campo de entrada.
2. Clique no botão "Chutar".
3. O sistema dirá se o número secreto é maior ou menor que o seu chute.
4. Tente acertar no menor número de tentativas possível!
