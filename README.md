# 🔢 Secret Number Game

This project is an interactive guessing game where the user tries to discover the secret number generated by the system. It marks my transition from pure HTML/CSS to dynamic programming logic with **JavaScript**.

## 🛠️ Technologies and Concepts Applied

* **JavaScript (ES6+):** Used for the entire game's logic.
* **DOM Manipulation:** Integration of the script with HTML elements (text, buttons, and input fields).
* **Responsive Voice:** Implementation of voice synthesis to make the game accessible and interactive.
* **HTML5 and CSS3:** Structure and styling of the visual interface.

---

## 📖 Development Journey (Programming Logic)

The project was built and evolved through two fundamental modules at Alura:

### 1. Diving into Programming with JavaScript
* **Workload:** 6 hours
* **Link:** https://cursos.alura.com.br/course/logica-programacao-mergulhe-programacao-javascript
* **Challenge:** Build the base of the game where the computer generates a random number and the user needs to guess it.
* **Solution & Learning:** I applied the fundamental concepts of **variables**, **conditionals (`if/else`)** to check if the guess was higher or lower, and **loops (`while`)** to manage the player's multiple attempts. It was my first practical contact with problem-solving through algorithms.

### 2. Exploring Functions and Lists
* **Workload:** 6 hours
* **Link:** https://cursos.alura.com.br/course/logica-programacao-funcoes-listas
* **Challenge:** Refactor the code to make it more organized, visually appealing, and add memory to the game.
* **Solution & Learning:** * **Functions:** Organized the code into functions with parameters and returns, facilitating reading and maintenance.
  * **Lists (Arrays):** Implemented a system so that the game does not repeat numbers that have been previously drawn, using list methods.
  * **Interactivity:** Improved the user experience by integrating JavaScript with HTML to display dynamic messages on the screen and clear the input field automatically.

## 🚀 How to Play

You can test the game right now through the link below:

🔗 [Online Game Link (Vercel)](https://jogo-numero-secreto-html-css-js.vercel.app/)

**Instructions:**
1. Type a number in the input field.
2. Click the "Guess" button.
3. The system will tell you if the secret number is higher or lower than your guess.
4. Try to get it right in the fewest number of attempts possible!
